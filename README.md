## About

Research software and simulation tools developed for the NASA FINESST project:

**Beyond Detection: Evaluating Space-Based Interferometry for Complementary Characterization of Potentially Hazardous Near-Earth Objects**

NASA Award: **80NSSC26K0350**

This project investigates space-based infrared interferometry for the characterization of near-Earth objects, with emphasis on shape reconstruction, rotational and binary properties, thermophysical modeling, and their implications for planetary defense.

## Status

This repository is under active development. Research software and associated datasets will be organized, documented, and released in accordance with the project's Open Science and Data Management Plan.

## License

The approved FINESST Open Science and Data Management Plan anticipates public release of project software under the **NASA Open Source Agreement (NOSA), Version 1.3**.

The final license and associated software-release metadata are currently being confirmed with Purdue University and NASA. No substantive project software has yet been publicly released from this repository.
